# Standards and Taxonomy

[Product documentation](../README.md)

Standards define the rules people and agents apply to design and implementation.
The taxonomy supplies shared terms and identifiers for describing product and
technical architecture, code, patterns, and runtime resources.

- [Standards and architecture decision records](14-standards.md) explains the
  centrally managed rules, how agents apply them, and how a project records its
  decisions and permitted exceptions.
- [Taxonomy](taxonomy/README.md) explains the vocabulary, its domains and
  registries, and how people and tools use and govern it.

The machine-readable sources live at the repository root in
[`standards/`](../../../standards/) and [`taxonomy/`](../../../taxonomy/).
