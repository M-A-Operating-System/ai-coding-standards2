# maos-prd-docs-updater

Run the `01_product_docs/prd-docs-updater` pipeline agent. Cross-checks the approved PRD against existing product documentation in docs/product/.

## Input

`$ARGUMENTS` — GitHub issue or PR number (e.g. `42`)

## Instructions

Follow the `run-agent` command with pre-filled arguments:
`run-agent 01_product_docs/prd-docs-updater $ARGUMENTS`
