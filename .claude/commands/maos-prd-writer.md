# maos-prd-writer

Run the `01_product_docs/prd-writer` pipeline agent. Drafts a Product Requirements Document for an appropriately-sized issue.

## Input

`$ARGUMENTS` — GitHub issue or PR number (e.g. `42`)

## Instructions

Follow the `run-agent` command with pre-filled arguments:
`run-agent 01_product_docs/prd-writer $ARGUMENTS`
