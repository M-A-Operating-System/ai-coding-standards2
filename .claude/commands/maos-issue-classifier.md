# maos-issue-classifier

Run the `01_product_docs/issue-classifier` pipeline agent. Classifies the issue as bug, feature, chore, or spike.

## Input

`$ARGUMENTS` — GitHub issue or PR number (e.g. `42`)

## Instructions

Follow the `run-agent` command with pre-filled arguments:
`run-agent 01_product_docs/issue-classifier $ARGUMENTS`
